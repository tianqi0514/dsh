# 0031：原生 DSH 写作与独立 Plate

状态：已接受，并以科研楼可研候选完成一次真实闭环验证；不等于所有生产边界已验收。

用户于 2026-09-20 批准执行 `CHUANSHEN_NATIVE_WRITING_REVIEW`。本专项优先于旧台账的业务顺序，但不改变其未完成验收状态。

DSH 拥有项目、Session、模型、主笔、Skill 加载和原生 Team。智库准备章节工作包，校验原生 Agent 提交的正文和绑定，拥有事实、计算、规则、文稿版本。DSH 路径不再以调用智库内层 Agent 作为写作实现。旧妙笔独立入口保留兼容。

Plate 是独立 Client 插件，使用 alpha.2 公开 Resource/Sidebar 扩展，不占用 Office 的 kind 或 .docx 协议；通过受信 Host 的白名单业务接口读写智库正文，不直连数据库。受控值的位置绑定、CAS、用户选择回执和 stale 闸门由服务保障。普通作者仍从项目及原生对话工作。

首轮交付验收以科研楼可研报告的真实上传、章节生成、计算、编辑、影响预览、部分应用和 Word/PDF 为准；静态节点和协议测试不代替真实模型/浏览器结果。服务器或模型不可用时明确记录未验，不宣布生产完成。

## 已落地的结果

- 原生 DSH 项目选择 Workspace、连接器、Skill 与主笔；`deepseek-v4-flash-0731` 按章节执行写作。
- 智库保存 43 项已确认事实、25 次确定性计算和 37 条正文绑定；报告完成 10 个章节。
- 土建单价 `2500 → 2700` 的变更产生 6 项确定影响和 1 项人工复核影响。预览前正文不变；选择性应用留下 2 个 stale 并被发布闸门拒绝；回滚形成新 v14，历史版本未被改写。
- Plate 独立打开 v14，DOCX/PDF 均由指定版本真实导出并渲染为 3 页、2 个表格；文件摘要与存储记录一致。
- 导出列表以服务端 `succeeded` 为成功状态；客户端同时兼容旧 `completed` 状态。下载标识先校验再发起请求。

## 不因本 ADR 推定完成的事项

- 多租户委托授权、多人协同、外部生产 MCP 和更多报告类型尚未由本闭环证明。
- 绑定可以证明来源和依赖，但不能替代业务人员对分析性叙述的判断。
- 当前 DOCX/PDF 是业务讨论稿版式；客户正式封面、自动目录、签发信息及跨页表头需要按最终模板另行验收。
